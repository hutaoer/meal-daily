## 同日追加 · 静态内容录入通道（用户问「静态数据如何录入」）
- 新增人工编辑态 `content/`：README 录入手册、`manifest.json`（`pinned[0]` = 首页 Banner 第一张；`excludeFromFeed` 只入库不上首页）、`entries/*.json`（一餐）、`dishes/*.json`（菜品）、两个 `_TEMPLATE.json`（下划线开头，脚本跳过）。
- 原因：**微信小程序运行时不能遍历目录 / 读包内 JSON**，数据必须编译进 JS。故 `scripts/sync-content.mjs`（Node 原生，无新依赖）把 JSON 编译成 `src/services/mock/generated.ts`（导出 `userContents/userDishes/userFeed`）；`feed.ts/contents.ts/dishes.ts` 各自 `[...user*, ...base*]` 合并，`feed.ts` 的 `bannerItems` 仍基于最终 `feed`，切分规则 §5.1 不变。
- 每个录入文件自动派生一张 `FeedItem`（title/subtitle/coverKey/date 取实体，meta/tags/coverHeight 自动生成，可用 `feed` 覆盖块改写）；顺序 = pinned → 其余按 date 倒序 → 内置 13 条。脚本校验文件名=id、id 格式、色块名、steps 序号连续等，失败不写产物。
- `package.json` 加 `content:sync` + `prebuild:weapp` + `pretest`；`dev:weapp` 经 `npm run build:weapp` 间接触发同步。watch 期间新增文件需手动跑一次 `yarn content:sync`。
- 示例：`content/entries/202611121.json`（pinned，Banner 第一张「【录入示例】雨夜的一碗热汤面」）、`content/dishes/d011.json`（青菜鸡蛋面，同时演示引用内置 `d008`）。最终 feed = 2 + 13 = 15 条，Banner 5 + 瀑布流 10。
- 测试改掉硬编码 13/7/10 规模断言（改为下限 + 新增 3 条录入通道用例，共 15/15）；PRD 新增 §14 并同步 §13.1~13.3 的数字。校验：`tsc --noEmit` 0 错误、`yarn test` 15/15、`yarn build:weapp` 成功、`dist/common.js` 含示例文案（`content/` 本身不打包）。

## 同日再迭代 · coverImgUrl 线上封面（用户否决本地图片方案）
- 用户给了公众号图片 CDN（`mmbiz.qpic.cn`）链接，先问「如何录入」。AI 一度按原约束下载/裁切成横版本地 JPG，**用户打断并明确改口**：不要本地图，直接在 `src/services/mock/generated.ts` 增加 `coverImgUrl` 字段展示线上图片链接，默认空则不展示。→ 清理了 `content/images/` 与 `src/assets/covers/` 的全部中间产物。
- 决策口径：**尊重用户指定字段与目标文件；generated.ts 是自动产物，不能手改**，实际录入落在 `content/*.json` + `scripts/sync-content.mjs`，同步后 generated.ts 里出现该字段（4 处：userContents / userDishes / userFeed×2）。
- 实现：`FeedItem` / `ContentItem` / `Dish` 加 `coverImgUrl?: string`；脚本 `cleanEntity` 给所有实体补默认值 `''`、`toFeed` 传给首页卡片、`validate` 只接受 `https://` 或空；`validateMockData()` 也加协议校验。
- 渲染：`ColorBlock` 新增 `imageUrl` → 有值用 `<Image mode="aspectFill">` 铺满，无值回退渐变色块；`FeedCard` Banner 有图时加**暗色蒙层**（rgba 28,16,10 0.10→0.74）保证白字可读；ContentCard / DishCard / 两个详情页都传该字段并去掉「待替换为本地图片」占位文案。
- 示例：`entries/202611121.json` 填了公众号链接（Banner 第一张为线上照片），`dishes/d011.json` 留 `""` 仍是色块；两个模板也带空值。
